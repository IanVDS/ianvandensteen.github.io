Spotify Album Art LED Matrix

A 64×64 HUB75 LED panel driven by a Raspberry Pi Pico 2 W that shows the album art of whatever’s playing on Spotify — fetched, decoded, and rendered entirely in firmware.

  • Pico 2 W
  • HUB75
  • OAuth / PKCE
  • JPEG decode
  • C / firmware
Image / GIF / video

Overview

The display polls Spotify for the currently playing track, downloads the album artwork, and paints it onto a 64×64 LED matrix. The interesting part is how much of that stack lives on the Pico: networking, auth, image decode, and panel timing all share the same constrained MCU.

System stack

  • Hardware — Raspberry Pi Pico 2 W driving a 64×64 HUB75 panel (Wi-Fi for Spotify, GPIO for the matrix).
  • Auth — Spotify OAuth with PKCE so the device can obtain tokens without embedding a client secret.
  • Firmware — C firmware that fetches now-playing metadata, pulls the JPEG album art, decodes it on-device, and renders frames to the panel.

Highlights

  • End-to-end path from Spotify API → pixels on HUB75
  • OAuth/PKCE flow suitable for an embedded client
  • On-device JPEG decode and LED matrix drive on Pico 2 W
